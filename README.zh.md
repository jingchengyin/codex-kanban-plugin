# Codex-Kanban-Plugin · 对话看板

[English](README.md) | [简体中文](README.zh.md)

专为 Codex 重度使用者设计，看板模式管理并发对话、工作事项和历史用量。

## 快速开始

目前只支持 MacOS，Windows 暂未适配，欢迎 PR 👏

### 安装

需要 macOS 桌面客户端。插件会优先使用本机已有的 Node.js 22.13+；找不到时，自动从 Node.js 官网下载并校验固定版本，缓存到 `CODEX_HOME/kanban/runtime`（默认 `~/.codex/kanban/runtime`）。首次下载需要联网，之后复用缓存。无需手动安装 Node.js、npm 依赖或运行构建命令。

#### 方式 1: AI 安装

把下面这段话发给 Codex，让它帮你安装：

```text
请帮我安装 Codex-Kanban-Plugin：https://github.com/jingchengyin/codex-kanban-plugin
从 main 分支添加插件市场，安装 codex-kanban-plugin@codex-kanban-plugin，并检查安装结果。
```

#### 方式 2: 手动安装

手动安装时，在「添加插件市场」中填写：

| 字段     | 值                                 |
| -------- | ---------------------------------- |
| 来源     | `jingchengyin/codex-kanban-plugin` |
| Git 引用 | `main`                             |
| 稀疏路径 | 留空                               |

添加市场后，安装 **Codex-Kanban-Plugin**。

#### 方式 3: CLI 安装

也可以通过 CLI 手动安装。首次安装需按顺序执行两条命令；如果已添加过市场，只需执行第二条：

```sh
# 添加插件市场
codex plugin marketplace add jingchengyin/codex-kanban-plugin --ref main

# 安装市场中的插件
codex plugin add codex-kanban-plugin@codex-kanban-plugin
```

安装参数的格式是 `插件名@市场名`，也可用 `-m 市场名` 指定市场。本插件和市场均命名为 `codex-kanban-plugin`。

### 更新

如果按上面的方式添加了 Git 市场，运行：

```sh
# 拉取 main 分支的最新内容，并更新已安装的插件
codex plugin marketplace upgrade codex-kanban-plugin
```

更新会沿用添加市场时指定的 Git 引用，上面的示例为 `main`。这条命令也会更新已安装的插件，无需卸载或再次执行 `plugin add`。更新完成后，关闭已打开的看板，再重新打开。

### 接入实时状态

正常打开 Codex 后，直接打开看板即可同步实时状态，**无需重启客户端**。在「连接与数据源」中可查看连接状态。

未加载或暂时无法获取状态的对话显示为「状态待同步」。

## 功能

- **工作事项：** 创建事项并关联多条对话，填写说明、验收清单和成果链接。可直接从对话卡片加入已有事项，或创建事项并关联当前对话；点击所属事项标签即可打开编辑。事项支持「待开始、进行中、待验收、已验收」，进度由用户手动确认；对话空闲或一轮执行结束不会自动通过验收。
- **工作回顾：** 查看最近 1、7、30 天的历史回合，按项目筛选，汇总已知 token、耗时、完成和中断情况，包含归档对话。缺失用量和不可读日志会单独标记。
- **看板与列表：** 看板按状态分列，每条对话只出现在一列，默认包含「状态待同步」的本地对话。自动布局在视图宽度不超过 900px 时使用紧凑列表，也可手动选择看板或列表。
- **卡片内确认：** 连接后，可在卡片中查看支持的待执行命令、文件 diff 或结构化问题，并提交原请求允许的决定或答案。桌面已处理或请求已结束时，旧按钮失效；暂不支持的请求仍需在原对话处理。确认结果会交回原对话。
- **需要关注视图：** 集中查看等待回复、未读和执行异常的对话，展示待答问题摘要或错误提示。等待时长从本次连接首次观察到等待开始计算，不代表问题实际发出时间。
- **完整卡片信息：** 模型、思考等级、计划/默认模式、目标状态、本轮 token 用量、耗时及最近一条用户输入。列表中的运行详情可展开查看。
- **搜索与筛选：** 搜索标题、项目、ID、最近一条用户输入或所属事项名称，按项目、运行状态和阅读状态筛选。当前只展示普通对话。支持「优先处理」「最近发消息」和「标题排序」；「优先处理」依次展示需要你处理、执行异常和未读的对话，等待中的对话按首次观察时间从早到晚排列。
- **记住视图：** 重新打开时保留页签、对话范围、筛选、排序和布局选择。
- **直接跳转：** 点击卡片直接打开原对话，不弹出详情框。
- **监听关系：** 卡片和列表显示「监听 xx」「被 xx 监听」，点击即可打开对应对话。关系来自最近一轮成功的对话等待记录，结束后保留，新一轮开始时重置。普通查看和即时状态快照不计入监听。
- **未读追踪：** 读取客户端保存的记录；存在多份记录时，可明确选择对应来源。
- **实时更新：** 默认直接跟随桌面对话的状态快照和增量更新。断线时保留本地对话和最后快照，明确标记状态并非实时，不可用的运行状态归入「状态待同步」。
- **Codex 外观：** 跟随宿主深浅色主题，默认英文，可切换中文。
- **数据保存：** 工作事项存放在 `CODEX_HOME/kanban/workspace.sqlite`；未设置 `CODEX_HOME` 时使用 `~/.codex/kanban/workspace.sqlite`。插件只读访问 Codex 本地对话数据；用户在卡片中提交的确认结果通过桌面原连接发送。
